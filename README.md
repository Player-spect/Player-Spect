## 🔐 Offensive Security

Mi principal área de interés actualmente es **Offensive Security**.

Estoy desarrollando una metodología basada en:

```text
Reconnaissance
      ↓
Scanning
      ↓
Enumeration
      ↓
Vulnerability Analysis
      ↓
Exploitation
      ↓
Privilege Escalation
      ↓
Post-Exploitation
      ↓
Pivoting
      ↓
Documentation
```

La idea no es solamente aprender herramientas, sino comprender **qué hacen, por qué funcionan y cómo utilizarlas dentro de una metodología de pentesting**.
